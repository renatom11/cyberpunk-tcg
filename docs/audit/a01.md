### AUD-memory-relapse-1 — Memory Relapse — class B4 (scope/condition error)

Printed text (`data/cards/wnc.json`, id `memory-relapse`):

> Spend a rival Unit. It can't ready until your next turn. If your ★ (Street Cred) is an even
> number, draw 1.

**Clause map (Leg B)** — script at `src/cptcg/cards/sets/wnc.py:95-103`

| # | Clause | Implementation | Verdict |
|---|---|---|---|
| 1 | "Spend a rival Unit." | `spend_one(c, c.rival_units(), then=after)` (line 102) → `dsl.spend_one` → `c.choose(cands, ...)`; `effects.choose` with an empty `values` and no `otherwise` returns immediately | OK when a rival Unit exists |

### AUD-bonnie-and-clyde-1 — Bonnie and Clyde — class B4 (may vs must)

Printed text (id `bonnie-and-clyde`):

> Defeat a rival Unit with power 4 or less. You may defeat 2 instead if a Rival controls at least
> 2 Gigs more than you.

**Clause map (Leg B)** — script at `src/cptcg/cards/sets/wnc.py:21-28`

| # | Clause | Implementation | Verdict |
|---|---|---|---|
| 1 | "Defeat a rival Unit" (mandatory — no "may") | `c.choose_many(..., 0, n, ...)` (line 25) with **lo = 0** | **WRONG — optional** |
| 2 | "with power 4 or less" | `c.rival_units(power_le(c, 4))` (line 25); `power_le` uses `c.power`, so modifiers count | OK |
| 3 | "You may defeat 2 instead" | `hi = n` where `n = 2` under the condition (line 23) | OK (the "may" is real here: sizes 1 and 2 must both be offered) |
| 4 | "if a Rival controls at least 2 Gigs more than you" | `len(c.gigs(c.rival)) >= len(c.gigs()) + 2` (line 23) — counts dice in the Gig areas | OK |

`choose_many(values, lo, hi, ...)` (`src/cptcg/core/effects.py:176-196`) builds one `Pick` per
combination of size `lo..hi`, so `lo=0` always adds the empty pick — a decline. The printed text
offers a choice of *how many* (1 or 2, and only when the Gig condition holds), never a choice of
*whether*. The script's own prompt string, `"Defeat up to %d"`, is the tell: "up to" is not on the
card. Correct bounds are `lo = min(1, len(cands))`, `hi = n`.

Probe (equal Gigs, two legal targets): the offered picks are sizes {0,1,2} over 2 candidates — 4
options where the text allows 2 (one per target).

Rulings checked: none of the 41 rulings address optional vs mandatory effect resolution, target
counts, or "up to"; the TRAP list (012, 015, 019, 025, 026, 030) is untouched — this is neither
BLOCKER redirect scope, GO SOLO slot vacation, once-per-turn scope, field size, squares-on-Gear nor
payment order. `docs/rules.md` grants optionality only where a card or keyword prints "you may"
(lines 91-92, 118, 132, 189). Corroboration from the set's own templating: every other WNC card
with an optional clause prints "You may …" explicitly (e.g. `maxtac-av`, `gilded-maton`,
`placide-voodoo-sentinel`) — and this card prints it for the second Unit only.

### AUD-unlikely-bond-1 — Unlikely Bond — class B4 (may vs must)

Printed text (id `unlikely-bond`):

> Bottom-deck a ready friendly Unit. If you do, bottom-deck a spent rival Unit.

**Clause map (Leg B)** — script at `src/cptcg/cards/sets/wnc.py:77-86`

| # | Clause | Implementation | Verdict |
|---|---|---|---|
| 1 | "Bottom-deck a ready friendly Unit." | `bottom_deck_one(c, [u for u in c.units() if not c.s.i_spent[u]], optional=True, then=after)` (line 86) | **WRONG — `optional=True` adds a decline the text does not print** |
| 1a | "ready" | `not c.s.i_spent[u]` | OK |
| 1b | "friendly" | `c.units()` = own field Units (`state.units`, excludes Gear) | OK |
| 2 | "If you do," | the second effect lives in `then`, which `dsl.bottom_deck_one` runs only after an actual pick | OK — correctly chained; verified by probe (no ready friendly Unit ⇒ nothing at all happens) |
| 3 | "bottom-deck a spent rival Unit" | `bottom_deck_one(c2, [u for u in c2.rival_units() if c2.s.i_spent[u]])`, mandatory (line 85) | OK; also correct that clause 1 still resolves when clause 3 has no target (probe) |

The card prints no "may". Across the whole card pool, every optional clause chained with "If you
do" prints the permission explicitly — `alt-cunningham-mother-of-daemons`, `dum-dum-maelstrom-triggerman`,
`el-sombreron-la-venganza-lenta`, `gilded-maton`, `goro-takemura-vengeful-bodyguard`,
`maman-brigitte-spirit-of-death`, `placide-voodoo-sentinel`, `panam-palmer-*` all read
"You may X. If you do, …". Unlikely Bond is the one card with "If you do" and no "may", so its
"If you do" covers the *unable* case (no ready friendly Unit), not a decline.

Counter-reading (why this is B4 and not a slam dunk): one could read "If you do" as itself the
marker of optionality, in which case `optional=True` is right and the card is simply templated
loosely. Authority order settles it — the text field prints no "may", and card text beats
everything. Worth flagging to the card-data owner if the physical card is ever re-checked.

Rulings checked: none apply — no ruling in `docs/rulings.md` covers optionality, bottom-decking
(022 only fixes deck order semantics, which the script follows through `ops.bottom_deck`) or this
card. No TRAP subject is touched.

## Unproven

- **S-SUSPICION — Memory Relapse / Corporate Surveillance target an already-spent rival Unit.**
  Both scripts pass the whole `c.rival_units()` (filtered only by cost, for Corporate
  Surveillance) to `spend_one`, so an already-spent Unit is a legal pick; `ops.spend` returns
  immediately for a spent card (`src/cptcg/core/ops.py:320-325`). For Corporate Surveillance the
  outcome is unobservable (probe: only spent cheap Unit on the board ⇒ no state change either
  way), so no test can distinguish it. For Memory Relapse it *is* observable — the script still
  applies "can't ready until your next turn" to a Unit it did not actually spend. I did not file
  this as a finding because both readings are defensible: ruling **013** ("'spend this Unit'
  requires a ready card") points at "no legal target", while the mainstream TCG convention is that
  a spend/tap effect may target an already-spent permanent and the rider still applies. Card text
  is silent. Flagging for a rules decision rather than freezing a guess into an xfail.
- **U-UNREACHABLE — Live with the Aftermath's candidate lists are snapshots.** Both `c.rival_units()`
  and `c.units()` are materialised when the Program resolves, and the two picks are then queued.
  If resolving the first defeat removed a Unit from the other player's list (a DEFEATED trigger
  that kills across the board), the second chooser could "defeat" an instance that is already in
  the trash — `ops.defeat` returns `False` for a card outside FIELD/LEGENDS — and end up defeating
  nothing while still controlling a Unit. I could not build a legal board that does this with the
  cards in this set (no printed DEFEATED trigger defeats a Unit on the other side), so there is no
  failing test and no finding.
- **N-NOTE — Over the Edge silently uses the best friendly d20.** `lim = max(d20)` rather than
  asking which d20 to use. The candidate set for any smaller d20 is a subset of the candidate set
  for the largest, so no reachable outcome differs; it is a search-space simplification in the
  same spirit as ruling 025, not a text deviation. Probe with `gig=[(20, 3), (20, 8)]` and rival
  Units of power 6 and 8: both are offered, which is what "a friendly d20" permits.

## Clean

Checked clause by clause, script and text agreeing in both directions:

- **wild-in-the-streets** — "Defeat a spent Unit." Mandatory `defeat_one` over the spent Units of
  *both* players (the text says "a spent Unit", unqualified, so your own count — probe: with only
  your own Unit spent, it is defeated). No target, no effect. Nothing extra.
- **carnage-at-the-colosseum** — "Play this Program for -1 €$ for each friendly Gig with 8+ value,
  to a minimum of 1 €$. / Defeat a rival Unit with less power than a friendly Unit."
  `self_cost = max(1, base - gigs_8plus(c))` counts only *your* Gigs with value ≥ 8 (probe: rival
  8+ Gigs do not reduce it; 6 friendly 8+ Gigs floor the cost at 1; a Gig of 7 does not count);
  `ops.play_cost` re-applies the same floor for other reductions. The defeat uses strict
  `power(u) < max friendly power` (probe: equal power is not a legal target; no friendly Unit ⇒ no
  defeat, since `best` falls back to 0).
- **over-the-edge** — "Defeat a Unit with power equal to or less than the value of a friendly
  d20." `<=` (not `<`), candidates from both players ("a Unit", unqualified), and no effect at all
  when you control no d20 (probe). See the N-NOTE above about `max`.
- **dont-fear-the-reaper** — "Spend all rival Units. Then, defeat a spent Unit." All rival Units
  spent first (probe: 3/3, including one already spent), then a mandatory defeat over every spent
  Unit on the table, yours included (probe: with no rival Units, your own spent Unit is the target
  — which is what the unqualified second sentence says).
- **live-with-the-aftermath** — "Each player defeats one of their Units." Each pick is offered to
  that Unit's own controller (`player=c.rival` for the rival's; probe confirms `pending.player == 1`),
  both mandatory, and a player with no Units simply does nothing. See the U-UNREACHABLE note.
- **les-elemens** — "Bottom-deck a Rival's lowest-power Unit. (If there are multiple, choose 1.)"
  `min` over rival Units, then a mandatory pick restricted to Units at exactly that power (probe:
  two tied Units ⇒ exactly 2 options; the 10-power Unit is not offered). Ruling 022 (bottom = index
  0) is satisfied by `ops.bottom_deck`.
- **corporate-surveillance** — "Spend a rival Unit with cost 4 or less." `cost_le(c, 4)` reads the
  printed cost (`c.d(u).cost or 0`), rival side only, mandatory. See the S-SUSPICION note about
  already-spent targets, which is unobservable for this card.
