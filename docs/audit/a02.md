| Unproven | 2 |

**Headline:** Shattered Memories turns a printed "may draw 5" into a forced draw, so playing it can
deck the Rival out (or you) against the owner of that "may" — a game-ending deviation, not a tempo
rounding error.

The three findings are `shattered-memories` (B4 may→must), `fool-on-the-hill` (B2 the "Reveal"
clause is never implemented, so the Rival decides blind), and `gunpoint-diplomacy` (B4 "the next
time this Unit attacks this turn" is granted as an until-end-of-turn permission).

## Findings

### AUD-shattered-memories-1 — Shattered Memories — class B4 (may → must)

**Clause.** Printed text (`data/cards/wnc.json`):

> Each player discards their hand and **may draw 5**.
> If the total number of discarded cards equals the value of a friendly Gig, draw 2.

#### Leg B — clause map

| # | Printed clause | wnc.py | Verdict |
|---|---|---|---|
| 1 | "Each player discards their hand" | 164-168 — loops `(c.player, c.rival)`, discards every card of each hand via `ops.discard` | correct; no choice needed, the whole hand goes |
| 2 | "and **may** draw 5" | 170-171 — `for p in (c.player, c.rival): c.draw(5, player=p)`, with the comment `# "may draw 5": always beneficial, auto` | **WRONG.** The "may" belongs to each player individually and is never offered. No `c.maybe(...)` / `optional=` anywhere. |
| 3 | "If the total number of discarded cards equals the value of a friendly Gig" | 163-166 accumulates `total` across **both** hands; 169 `vals = set(c.gig_values())` (no player arg → friendly) | correct |
| 4 | "draw 2" | 172-173 — `c.draw(2)` for the controller | correct |

The script's own comment states the premise: *"always beneficial"*. It is not. `ops.draw`
(src/cptcg/core/ops.py:223) reads *"Drawing from an empty deck loses the game (rival wins)"* and
calls `end_game(s, winner=1 - player, reason=EndReason.DECKOUT)`. `docs/rules.md` ("Win
conditions"): *"**Deckout.** If you are required to draw a card but have no cards left in your deck,
your **Rival** immediately wins."* So a player holding 0-4 cards in deck strictly prefers to
decline, and the printed "may" is exactly what lets them. Forcing it converts a card-flow Program
into a two-sided deckout gun — the controller can deck the Rival out, and can also lose on the spot
by playing their own card.

**Rulings checked.** 020 (no hand size limit — nothing forces the draw for hand-size reasons);
008 (win check is Start Phase step 0, so a mid-main deckout ends the game right there, it is not
deferred); 035 (the Program resolves outside every area, which is why its own copy is not part of
the discarded hand — matches the script and the existing `test_shattered_memories`). None of the 41
rulings covers "may" as auto-resolved; the trap list (012/015/019/026/030/025) does not touch this.
Note that `effects.maybe` exists precisely for this and is used elsewhere in the same file
(`the-heist`, line 134), so the omission is not a missing facility.

Not classed **D**: no ruling licenses collapsing a printed "may". Not classed **A**: the alternative
reading ("may" as flavour) is refuted by the deckout rule making the choice materially live.

### AUD-fool-on-the-hill-1 — Fool on the Hill — class B2 (missing clause)

**Clause.** Printed text:

> **Reveal the top 2 cards of your deck.** A Rival chooses whether you add them to your hand or
> trash them. If you trash them, draw 2.

#### Leg B — clause map

| # | Printed clause | wnc.py | Verdict |
|---|---|---|---|
| 1 | "**Reveal** the top 2 cards of your deck" | 143 `top = c.top(2)` — reads them into a Python list only. The `c.choose(...)` on line 155 passes **no** `revealed=` argument. | **UNIMPLEMENTED.** The cards stay in `Zone.DECK` and stay hidden from the chooser. |
| 2 | "A Rival chooses whether you add them to your hand or trash them" | 155 `c.choose([True, False], decide, ..., player=c.rival)` | correct — two options, seat = rival |
| 3 | "you add them to your hand" | 148-150 — both cards to hand | correct |
| 4 | "or trash them" | 151-153 — `move(..., Zone.TRASH)` for both | correct |
| 5 | "If you trash them, draw 2" | 154 `c2.draw(2)`, only in the trash branch, for the controller | correct |

`effects.choose` documents the exact facility clause 1 needs: *"`revealed` names the instances this
question has *shown* to the chooser — the top cards a peek looked at. Declare it whenever the effect
read a card the chooser could not otherwise see; `core.view` pins exactly what is declared here"*
(src/cptcg/core/effects.py:152-155). `core.view.knows_identity` (view.py:128) for a `Zone.DECK`
instance returns `inst in _pinned(s, me)`, and `_pinned` returns `s.pending.revealed` — empty here.
So seat 1 is asked to choose between hand and trash for two cards it cannot read. The whole point
of the card is that the Rival makes an *informed* hostile choice; blind, the clause is inert and the
decision degenerates.

This is not a cosmetic/UI gap: the search agents and `view.determinize` build their information sets
from `knows_identity`, so the Rival's decision is taken on a determinized guess rather than the
revealed cards.

Contrast with `three-mouths-one-desire` (line 179) which routes through `effects.search_top`, and
that helper *does* declare `revealed=tuple(cards)` (effects.py:276-277) with the comment *"The peek
is real"*. The facility is used correctly one card away; Fool on the Hill simply does not call it.

**Rulings checked.** 018 (hidden mulligan) and 031 (face-down Legend texts inactive) are the only
information-visibility rulings; neither covers a printed "Reveal". 022 (deck order: index −1 is the
top) confirms `ops.top_cards` returns the right two cards. None of 012/015/019/025/026/030 applies.

Not classed **D**: no ruling makes reveals optional. Not **A**: "Reveal" has one meaning.

### AUD-gunpoint-diplomacy-1 — Gunpoint Diplomacy — class B4 (scope: "the next time" → all turn)

**Clause.** Printed text:

> Give a friendly Unit these effects. If you have less ★ (Street Cred) than a Rival, they instead
> choose one effect for you.
> - **The next time this Unit attacks this turn**, it may attack ready Units.
> - Give this Unit +3 power this turn.

#### Leg B — clause map

| # | Printed clause | wnc.py | Verdict |
|---|---|---|---|
| 1 | "Give a friendly Unit these effects" (plural → both, mandatory target) | 215 `c.choose(c.units(), give, ...)` — friendly Units, not optional; 214 `c2.choose_one(opts, both=True)` | correct |
| 2 | "If you have less ★ than a Rival, they instead choose one effect for you" | 211-212 `if c2.less_cred(): c2.choose_one(opts, player=c2.rival)` — strictly-less, the Rival is the chooser, one effect | correct |
| 3 | "**The next time** this Unit attacks **this turn**, it may attack ready Units" | 209 `c3.mod("attack_ready_units", u)` → `effects.mod` with `until_my_next_turn=False` → `turns=0` → a plain until-end-of-turn mod | **WRONG SCOPE.** Nothing consumes the grant on use. |
| 4 | "Give this Unit +3 power this turn" | 210 `c3.temp_power(u, 3)` | correct |

Clause 3 is read by `legal.attack_targets` (src/cptcg/core/legal.py:57): `ready_ok =
s.has_mod("attack_ready_units", attacker)`. A grep of the whole of `src/` finds exactly two
occurrences of the string `attack_ready_units` — wnc.py:209 and legal.py:57. Nothing removes it
after an attack, so it is a permission that lasts the rest of the turn rather than one attack.

That the difference is reachable, not theoretical: `attack_targets` is consulted per attack, and the
set contains cards that ready a friendly Unit mid-turn — `wraith-marauders` (wnc.py:928-936, "ready
a friendly spent Unit after a steal"). A Unit given the Gunpoint grant can therefore attack a ready
Unit, be readied, and attack a second ready Unit in the same turn, which the printed "the next
time" forbids.

`docs/effects-authoring.md` names the correct pattern for exactly this wording, which is what makes
this a deviation from house style and not an accepted approximation:

> "The next time ... this turn" effects that outlive a Program: register a listener,
> `c.mod("listener", c.player, fn)` where `fn(state, ev)` runs on every event until end of turn.

**Rulings checked.** 011 (as many reactions per attack as the defender wants) and 012 (BLOCKER
redirect scope, Uncertain) — neither touches who may be *targeted*; the test deliberately avoids
BLOCKER Units so no redirect window opens. 024 ("an attacker is spent after attacking") is what
makes a second attack require an outside ready effect. 019 (once-per-turn scope, Uncertain) is a
*Call a Legend* ruling and does not reach "the next time this Unit attacks"; this finding is not
about a once-per-turn counter but about a one-shot permission that is never consumed, so the
presumed-**D** trap list does not cover it. 026 (field size, Uncertain) and 025 (payment order) are
untouched.

Not **A**: "the next time ... this turn" can only mean one attack — otherwise the clause would read
"this turn, this Unit may attack ready Units", which is how Towerfall/Pyramid Song phrase durations
on the same page.

## Unproven

### U-UNREACHABLE — Chrome Reverie resolves its two clauses in reverse printed order

`chrome-reverie` (wnc.py:108-112) queues the "a rival Unit can't attack" question first (109) and
the "you may Call a Legend for free" question second (112). Both go through `ops.ask`, which does
`s.stack.append(AskStep(choice))` (ops.py:167-169) — a LIFO stack — so the *Call* question is asked
**before** the can't-attack question. The existing `test_chrome_reverie_locks_attacker_and_may_call`
answers the Call first, which confirms the order.

I could not build a state where the order is observable in printed-text terms. The only way the
Call could change the can't-attack decision is a `CALL` trigger that removes a rival Unit from the
field, and there is none: the seven `on_call` hooks in wnc.py are v-streetkid (trash 3 / add a
BRAINDANCE Program), wakako-okada (rival Unit −2 power / draw 1), dexter-deshawn-off-the-grid
(friendly Unit +2 / draw 1), padre (**spend** a rival Unit / draw 1 — spending does not remove it),
muamar-reyes (no-defeat-in-fight / draw 1), viktor-vektor (search top 5), dum-dum (defeat a
*friendly* Gear / draw). Calling also cannot add a rival Unit. The candidate list on line 109 is
snapshotted at script time either way, so no reordering of the two answers changes any zone, power,
Gig or keyword. Recorded rather than dropped because a future `CALL` Legend that bounces or defeats
a rival Unit would make it live.

### N-NOTE — `offer_call_free` lets the controller pick *which* face-down Legend flips

`chrome-reverie` line 112 calls `effects.offer_call_free` (effects.py:386-391), which presents each
face-down Legend as its own option. `docs/rules.md` says *"flip one face-up at random"* / *"without
looking first"*, and ruling 041 only constrains the once-per-turn limit. With all slots unknown the
options are interchangeable, so this is normally a no-op; it stops being one once a slot's identity
is known to the controller (`ops.call_legend` and `effects.look_at` both set `i_known`). This is
engine-level behaviour shared by every card that Calls, not something `chrome-reverie` does, so it
is out of this batch's scope — recorded only so the next audit of `offer_call_free` has the pointer.
Style/scope note only; no test written.

## Clean

Seven cards checked clause by clause against the JSON text and found to implement it, in both
directions (no missing clause, no extra effect):

- **chrome-reverie** (106-113) — "A rival Unit can't attack until your next turn" → 109, mandatory
  `choose` over `rival_units()`, `mod("cant_attack", u, until_my_next_turn=True)`; `effects.mod`
  sets `turns=1` when the Program is played on your own turn, which is the printed duration.
  "If you control a min Gig" → 111 `c.min_gigs()` (friendly, dice showing face 1). "you may Call a
  Legend for free" → 112 `offer_call_free`, which is optional and bails via `ops.can_call_free`
  when the once-per-turn Call is already used — ruling **041** (*"Call a Legend may be used only
  once per turn even if a game action tells you to"*) and the card's own reminder text both
  satisfied. No extra effect. Clause-ordering caveat under Unproven.
- **all-is-lost** (116-122) — "Trash 3" → 119 `trash_top(3)` (ruling **022**: from the top,
  order preserved into the trash; does not trigger deckout, correct since trashing is not drawing).
  "Add a Unit from among them to your hand" → 120, filtered to `UNIT` and restricted to `ts`, the
  three just trashed, not the whole trash; mandatory, as printed. The trash is a public zone
  (view.py `PUBLIC_ZONES`) so no reveal declaration is owed.
- **the-heist** (125-136) — "Trash 4" → 128. "Add a Gear from among them to your hand" → 135,
  filtered to `GEAR` over `ts`, mandatory. "If that Gear's cost equals the value of a friendly Gig"
  → 129 `vals = set(c.gig_values())` (friendly) and 133 against the Gear's printed cost.
  "you may play it for free instead" → 134 `c2.maybe(... c3.play_free(g))` — a real "may", and
  `play_free` prompts for a host (`legal.gear_hosts`) and passes `cost=0`. The card is added to hand
  first and then played from hand, which lands in the same place as the printed "instead".
- **three-mouths-one-desire** (177-179) — "Search the top 3" → `search_top(3, ...)`, which declares
  `revealed=tuple(cards)` so the searcher legitimately sees all three (ruling **022** for top-of-deck
  order). "Add 1 to your hand" → `lo=1`. "You may add 1 more for each friendly min Gig" →
  `hi=1 + len(c.min_gigs())`, friendly dice showing 1. "Bottom-deck the rest" → `search_top`'s own
  `_done`, in chosen order, which ruling **022** permits (*"Bottom-deck puts cards on the bottom in
  any order"*). `choose_many` clamps `hi`/`lo` to a short deck without crashing.

  choose both instead" → `both=c.less_cred()`, strictly-less. "Give all rival Units −5 power this
  turn" → 186, every rival Unit, `temp_power` (turn-scoped). "Bottom-deck all rival Units with
  power 0" → 188, recomputed inside the continuation so it sees the −5 already applied; ruling
  **029** (*"power floors at 0 — cards like Towerfall ... only make sense this way"*) is what makes
  the pair work, and `ops.power` honours it. With `both=True` the `later()` + `reversed()` pairing
  in `choose_one` runs option 1 before option 2, i.e. printed order. `s.units()` returns a fresh
  list, so bottom-decking while iterating is safe.
- **pyramid-song** (193-202) — "If a friendly d4 is a min Gig" → 196 `any(k == 4 and v == 1 for k, v

  (one Unit, via `temp_power_one`). "Bottom-deck a rival Unit with power 0" → 200, one Unit, filtered
  by `c2.power(u) == 0` at resolution time and mandatory as printed. Under `both` the −4 resolves
  first (same `later`/`reversed` ordering), so a Unit knocked to 0 by clause 1 is a legal bottom-deck
  target for clause 2 — again ruling **029**.
- **nocturne-op55n1** (219-230) — "If your fixer area is empty, play this Program for 1 €$" →
