## Findings

### AUD-gorilla-arms-1 — the extra steal cancels one of the attack's own steals — class B5

**Card**: gorilla-arms (`wnc.json`: "The first time this Unit steals 1 or more Gigs each turn,
steal a rival Gig with a value not shared by a friendly Gig.")
**Script**: `src/cptcg/cards/sets/wnc.py` lines 1024-1033.

#### Leg B — clause map

| # | Printed clause | Implementation | Verdict |
|---|---|---|---|
| 1 | "The first time ... each turn" | L1027 `c.once("steal")`, short-circuited after the host test so it is only consumed on a host steal | OK (ruling 019 default, `once_per_turn_scope = "turn"`) |
| 2 | "this Unit steals 1 or more Gigs" | L1027 `e[0] == "steal" and e[1] == c.host()`; the event is `("steal", unit, thief, sides, value)` (`steps.do_steal`), so `e[1]` is the stealing Unit and `c.host()` is the equipped Unit | OK |
| 3 | "steal a rival Gig" | L1028-1031 `push_steals(c2.s, c2.host(), [i])` over `c.gigs(c.rival)`; mandatory `c.choose` (the text is not "may") | **the steal happens, but see below** |
| 4 | "with a value not shared by a friendly Gig" | L1029-1030 `mine = set(c.gig_values())` (gear owner's dice, read at resolution time, so the die just stolen counts as friendly) and `v not in mine` | OK |

Clause 3 is where it breaks, and the defect is one of *ordering*, not of selection. A Gig-area
attack queues one `StealOneStep` per die (`steps.push_steals`), each holding a **snapshot index**
into the victim's Gig list; the steps are pushed in ascending order so the highest index resolves
first and the lower ones stay valid. Gorilla Arms' extra steal is queued from inside the dispatch
of the *first* of those steals, so it sits on top of the stack and resolves **between** them. It
removes a die, the victim's list shrinks, and the remaining `StealOneStep` finds
`self.index >= len(s.gig[victim])` (`steps.py` L296) and returns without stealing.

Net effect: a card that reads "steal a rival Gig" *in addition to* the steals that triggered it
ends up substituting for one of them. Nothing in the printed text licenses that. Classified B5
(invariant violation — a queued steal silently fizzles); the repair may well belong in
`push_steals`/`StealOneStep` (stable die identity instead of an index snapshot) rather than in the
card, but the only card in the pool that reaches it from its own trigger is this one.

**Rulings checked**: 005 (stolen dice are not rerolled — irrelevant to the count), 009
(empty Gig area / dice leaving mid-attack: "if it empties after the declaration the attack proceeds
and steals nothing" — that covers an *empty* area, not an area that still holds a stealable die),
019 (once-per-turn scope — the `once` key is per card per turn, matching the default). No ruling
sanctions dropping a queued steal while dice remain.

### AUD-satori-sword-of-saburo-1 — a GO SOLO Legend on the field is not counted as a rival Unit — class B4 (scope)

**Card**: satori-sword-of-saburo ("(Equip to a friendly Unit or face-up Legend.) When this Unit
wins a fight against a rival Unit, draw 1.")
**Script**: `wnc.py` lines 1096-1101.

#### Leg B — clause map

| # | Printed clause | Implementation | Verdict |
|---|---|---|---|
| 1 | "(Equip to a friendly Unit or face-up Legend.)" | engine-side (`legal.gear_hosts`), not the script | OK |
| 2 | "When this Unit wins a fight" | L1099 `e[0] == "fight_won" and e[1] == c.host()`; `("fight_won", winner, loser, margin)` is dispatched from `steps.fight` | OK |
| 3 | "against a rival Unit" | L1099 `c.d(e[2]).type is UNIT` — the **card type** of the loser | **wrong scope** |
| 4 | "draw 1" | L1100 `c.draw(1)`, defaulting to the Gear's controller | OK |

Clause 3 asks whether the defeated card is a Unit *on the field*. The script asks whether its
printed card type is Unit, and those differ for exactly one board state: a Legend played to the
field with GO SOLO. `docs/rules.md` (Keywords) defines GO SOLO as "Pay this Legend's cost to **play
it as a ready Unit**", and ruling 015's default says the same in as many words:

> | 015 | A `GO SOLO` Legend on the field — still spendable as an Eddie? Does it hold its Legend
> slot? | **Not spendable** (it is a Unit now); its slot sits empty ... | `go_solo_vacates_slot` =
> true | Uncertain |

The Uncertain status attaches to the *slot* question; "it is a Unit now" is the premise both
readings share. The engine agrees everywhere else: `GameState.units` (state.py L201-205) returns
every non-Gear card on the field, which is why such a Legend is a legal attack target at all
(`legal.attack_targets` L61) and why the sibling card in this very batch — Overwatch, `wnc.py`
L1114-1123 via `c.rival_units()` — *does* defeat one as "a spent rival Unit". Two cards in the same
90-line range read the same two words ("rival Unit") opposite ways; the control test pins Overwatch's
reading, which is the one the rules text supports.

The counter-reading, and why it loses: an earlier batch argued from
`tests/cards/audit/test_a08.py::test_dying_night_ready_2_only_when_the_host_is_a_unit` that "this
Unit" excludes a Legend, citing zetatech-faceplate's explicit "this Unit **or Legend**". That
argument is about a Legend sitting **in the Legends area**, which is not on the field and is not a
Unit under any reading. It does not reach a Legend that has been played as a Unit. Note also that
Satori's own host clause is scripted correctly for this: `e[1] == c.host()` has no type test, so a
Legend host that GOES SOLO does trigger the draw when it wins — the script is already inconsistent
with itself about what a Legend on the field is.

**Rulings checked**: 015 (quoted above — applies), 032 (GO SOLO PLAY triggers: "GO SOLO reads 'pay
this Legend's cost to play it as a ready Unit'" — applies, same premise), 034 (a Legend leaving the
field is removed from the game; the test asserts `Zone.REMOVED`, confirming the fight really was
won against it), 017 (only Units are legal attack targets — the attack in the test is legal, which
is itself evidence the engine counts the Legend as a Unit), 010/029 (power floor and 0-power
fights — not engaged, 10 vs 8).

## Unproven

**S-SUSPICION — overwatch-panams-gift and the GO SOLO Legend on the field.**
I suspected Overwatch of the same scope error as Satori and wrote the test: it **passed**. A Legend
played to the field with GO SOLO is in `c.rival_units()` and is defeated by "Defeat a spent rival
Unit" exactly as the printed text says. Recorded because it is the evidence that the two cards read
the same two words differently, and because `tests/cards/test_audit_shape.py` keeps passing
scenarios out of the audit directory — the code and its result are under AUD-satori-sword-of-saburo-1
above.

**U-UNREACHABLE — sandevistan on the Rival's end of turn.**
"At the end of **your** turn" is scripted as `e[1] == c.player`, so I tried to catch it readying the
host at the end of the Rival's turn. No board distinguishes the two readings: with `active=1`,
`do(s, EndTurn())` runs straight on into the controller's own Start Phase, which readies every spent
card anyway (ruling 001) — my probe saw the host ready, from the Start Phase and not from the Gear.
The scope test in the script is right by reading; there is nothing to assert either way.

**U-UNREACHABLE — deadman-transmitter replaces the defeat of a Legends-area host.**
`would_defeat` (L1104-1110) fires for whatever `c.host()` is, but the printed text says "If **this
Unit** would be defeated". A face-up Legend in the Legends area is a legal Gear host and is not a
Unit, so the replacement should arguably not apply to it. I could not build a legal game that
defeats a Legend while it sits in the Legends area: `ops.defeat` returns False immediately for any
card outside FIELD/LEGENDS, and no card in the set targets a Legends-area Legend with a defeat
(the ones that defeat Legends — jackie-welles-mamas-favorite — do it to a Legend on the field,
where it *is* a Unit and the replacement is correct). No failing test, so no finding.

**N-NOTE — adrenaline-converter grants ADRENALINE to a Legends-area host.**
`kw_mod` (L1038-1041) returns True for `inst == c.host()` whatever the host is, and I confirmed by
probe that `has_keyword(s, <face-up Legend in the Legends area>, ADRENALINE)` is True. The text says
"this Unit has ADRENALINE" (contrast zetatech-faceplate's "this Unit **or** Legend"), so under the
reading used by `test_a08.py::test_dying_night_ready_2_only_when_the_host_is_a_unit` this is a
scope error. It has no reachable consequence: ADRENALINE only lets a card attack the turn it is
played (`rules.md` Keywords; `legal.py` L41), a Legend in the Legends area cannot attack, and once it
GOES SOLO it is on the field carrying GO SOLO, which already clears the same Lag check. Style only.

**N-NOTE — arasaka-emergency-radioport offers a Call that cannot happen.**
L1077-1078 asks "Call <name> for free?" before checking `ops.can_call_free`; `c.call_free` then
does nothing if the once-per-turn Call is spent (ruling 041, and `offer_call_free` in
`effects.py` L386-391 shows the guarded pattern). The outcome matches the printed reminder text
"(You may only Call a Legend once per turn.)" either way — only a dead prompt is added.

**N-NOTE — overwatch-panams-gift is illegal to activate with an empty hand.**
`legal=lambda c: bool(c.hand())` (L1121) is a condition the printed cost line does not state. It can
only ever save the controller from paying 1 €$ and spending the Gear for nothing (with no cards to
discard, `picks` is empty and the `if picks:` guard at L1116 skips the defeat), so I could not
construct a board where the added restriction costs anyone anything.

## Clean

Checked clause by clause against `wnc.json` text, `rules.md` and the 41 rulings; no deviation found.

- **adrenaline-converter** — "If a Rival controls at least 2 more Gigs than you, this Unit has
  ADRENALINE": `len(c.gigs(c.rival)) >= len(c.gigs()) + 2` is exactly "at least 2 more", counted in
  dice, and `kw_mod` re-reads it on every `has_keyword` call so a mid-turn steal flips it (the
  conditional-grant contract in `docs/effects-authoring.md`). Host scope correct. (See the N-NOTE
  above for the Legends-area host.)
- **tetratronic-rippler** — "When this Unit or Legend is spent, search the top card of your deck.
  You may trash it. (Otherwise, keep it on the top of your deck.)": host-spent trigger as for
  zetatech; `c.top(1)` is the top card (ruling 022: index −1 is the top); `c.maybe(..., revealed=top)`
  is the "you may", declared as revealed so the peek is modelled; declining leaves the card in the
  deck — probed: deck 2 → deck 2, trash 0.
- **netwatch-netdriver** — "When this Unit or Legend is spent, draw 1": one-line, exact; the draw
  goes to the Gear's controller, and both host kinds fire because `ops.spend` dispatches for
  FIELD and LEGENDS alike.
- **arasaka-emergency-radioport** — "you may look at a friendly face-down Legend" →
  `c.choose(c.legends(faceup=False), ..., optional=True)`, `legends()` defaulting to `c.player`
  (friendly) and filtered to face-down; `c.look_at` marks it known to that player only; "If that
  Legend is ARASAKA or has GO SOLO" → `"ARASAKA" in d.tags or GO_SOLO in d.keywords`; "you may Call
  it for free" → `c.maybe(... c3.call_free(l))`, which honours the once-per-turn Call
  (ruling 041, `ops.can_call_free`). Probed the negative branch: looking at Padre (no ARASAKA tag,
  no GO SOLO) ends the effect with no Call prompt and leaves every Legend face-down.
- **sandevistan** — "At the end of your turn, ready this Unit or Legend": `e[0] == "end_turn" and
  e[1] == c.player` is "your turn" for the Gear's controller (not the active player), the
  `c.host() >= 0` guard keeps an unequipped instance inert, and `c.ready` is orientation-only so it
  works for a Unit and for a face-up Legend spent as an Eddie (rulings 001, 003).
- **deadman-transmitter** — "If this Unit would be defeated, defeat its 'DEADMAN TRANSMITTER'
  instead": `would_defeat` returns True only for the host, so the host's defeat is fully replaced
  (`ops.defeat` L437-444 returns False and skips the move, the DEFEATED triggers and the "defeated"
  event) and the Gear defeats itself; a defeat aimed at the Gear itself is not replaced, so there is
  no loop. Probed with a non-combat defeat as well as the existing fight case: host stays on the
  field, Gear goes to the trash.
- **overwatch-panams-gift** — "QUICK 1 €$, ⊡: Discard 1. Defeat a spent rival Unit with cost equal
  to or less than the discarded card's cost": `Ability(cost=1, self_spend=True, quick=True)` matches
  the printed cost line under ruling 030 (⊡ on a Gear spends the Gear, host untouched — the
  presumed default, and the script does not deviate); the discard is from the controller's own hand
  and the defeat candidates are rebuilt **after** it, from `rival_units()` filtered to spent and
  `cost <= lim` (`<=`, matching "equal to or less than"); the defeat is mandatory, as printed, and
  simply finds no candidate when none qualifies. (See the N-NOTE on the empty-hand legality guard.)
