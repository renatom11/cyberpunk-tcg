## Findings

### AUD-jackie-welles-mamas-favorite-1 — B4 (scope/condition error: a<->all)

**Card:** `jackie-welles-mamas-favorite` (MS01-WNC 73, Green Legend, cost 6, power 8).

**Printed text**
```
GO SOLO
If a friendly Unit would be defeated, you may pay 1 €$ to defeat this Legend instead.
(Remove it from the game.)
```

**The clause:** "If a friendly **Unit** would be defeated".

#### Leg B — clause map

| # | Clause | wnc.py | Verdict |
|---|---|---|---|
| 1 | `GO SOLO` (keyword) | — (JSON `keywords`, engine-implemented) | ok |
| 2 | "If a friendly Unit would be defeated" | 1351-1354 `would_defeat(c, inst)`; `c.s.i_owner[inst] != c.player` (friendly ✓) **and `c.d(inst).type is not UNIT` → bails out** | **wrong scope** |
| 3 | "…would be defeated" as a replacement | 1351 `would_defeat` hook + `defeat(..., allow_replace=False)` at 1363/1367/1369 | ok |
| 4 | "you may" | 1368-1369 `c.choose([True], …, optional=True, otherwise=<defeat as normal>)` | ok |
| 5 | "pay 1 €$" | 1353 affordability gate `available(..., exclude=c.inst) >= 1`; 1365 `pay(..., 1, exclude=me)` | ok |
| 6 | "to defeat this Legend instead" | 1367 `defeat(c2.s, me, allow_replace=False)` | ok |
| 7 | "(Remove it from the game.)" | 1366 sets `F_GO_SOLO`, so `ops.defeat` sends her to `Zone.REMOVED` | ok |
| — | *extra, not in the text*: `c.s.i_zone[c.inst] is not Zone.LEGENDS` (1353) | see finding 2 | extra |

Clause 2 is the defect. `c.d(inst).type` is the **printed card type**, so a Legend that was played
to the field with GO SOLO — which every other part of this engine and this very file treats as a
Unit — can never be the subject of the replacement.

Why a GO SOLO Legend on the field is a "friendly Unit":

* `docs/rules.md`, Keywords: "`GO SOLO` — Pay this Legend's cost to **play it as a ready Unit**."
* `docs/rulings.md` 015 (Uncertain): "A `GO SOLO` Legend on the field — still spendable as an
  Eddie? … **Not spendable** (**it is a Unit now**)". The finding does not touch the Uncertain half
  of 015 (slot vacation / spendability); it uses only the ruling's own statement of what the card
  *is* once it is on the field, which is the same in both readings.
* `docs/rulings.md` 032: a Legend's `PLAY` trigger fires when it GOES SOLO, "GO SOLO reads 'pay this
  Legend's cost to **play it** as a ready Unit'".
* The engine agrees everywhere else: `state.units()` (src/cptcg/core/state.py:201) returns every
  non-Gear card on the field, so a solo'd Legend is a legal attack target, can be chosen by Goro
  Takemura's "a friendly Unit" list (wnc.py:1404) and fires Yorinobu's "friendly **ARASAKA Unit**
  attacks" trigger (wnc.py:1417) — that one tests tags only and never the card type.

**Rulings checked:** 015 (used, as above), 027, 032, 033, 034 (a Legend leaving the field is removed
from the game — consistent with the parenthetical), 010/009 (defeat sources), 025 (payment order —
untouched: the script pays through `ops.pay`, which is the ruling's default auto-payer, and only
excludes Jackie herself, exactly as `engine.activate` does for a Legend's own ⊡ cost).

**Not covered by the trap list:** this is neither BLOCKER redirect scope, nor GO SOLO *slot
vacation*, nor once-per-turn scope, field size, squares-on-Gear, nor payment order.

### AUD-jackie-welles-mamas-favorite-2 — B4 (scope/condition error: a condition the text never states)

**Card:** `jackie-welles-mamas-favorite`.

**The clause:** the same sentence, read from the other side — "**this Legend**", with no statement
anywhere in the text that the ability only works out of the Legends area.

#### Leg B — clause map

The map above applies; this finding is the "extra" row of it:

| Script condition | wnc.py | In the printed text? |
|---|---|---|
| `not c.in_play()` → bail | 1352 | yes — a card that is not in play has no active text (ruling 031) |
| `c.s.i_zone[c.inst] is not Zone.LEGENDS` → bail | 1353 | **no** |

Jackie carries GO SOLO herself (cost 6), so "Jackie on the field" is an ordinary line of play, not a
corner case. Once she is there her text is still active — she is a face-up card in play, which is
precisely the set of cards `ops._rebuild_active` collects, and ruling 032 confirms a Legend's own
text works while it is on the field ("GO SOLO … only makes sense this way"). Nothing in
`docs/rules.md` or `docs/rulings.md` switches a Legend's printed ability off when it plays as a
Unit; ruling 027 only removes ⊡ effects for the turn it arrives, through Lag, and this ability is
not a ⊡ ability.

The implementable reading is closed, not circular: the subject of the replacement is still "a
friendly Unit" other than her (clause 2 above filters `inst`), and the replacement itself calls
`defeat(..., allow_replace=False)`, so nothing recurses.

**Rulings checked:** 031 (face-down Legends have no active text — the reason `in_play()` is right
and the zone test is not), 032, 034 (she is removed from the game either way, so the parenthetical
still holds on the field), 015 (its Uncertain half — slot vacation — is not relied on).

## Unproven

**S-SUSPICION — `alt-cunningham-soulkiller-architect`, when the min-Gig count is read.**
"Your next Program this turn plays for -1 €$ for each friendly min Gig, to a minimum of 1 €$."
The script snapshots the count at activation: `c.mod("cost_next_program", c.player, -len(c.min_gigs()))`
(wnc.py:1332) stores a fixed number, and `ops.play_cost` later just adds it. I wrote the probe
(activate Alt with one min Gig, then use Hanako Arasaka's ⊡ to swap a rival 1 onto my side, making
two min Gigs, then read the cost of a 3-cost Program): the cost stays 2, i.e. the second min Gig is
ignored. **The probe passes under the snapshot reading, so I am filing no test.** Both readings are
defensible — "plays for -1 €$ for each friendly min Gig" can be read as a price fixed when the
effect resolves, or as a modifier evaluated when the Program is actually played — and a strict-xfail
for the second reading would freeze a coin-flip into the repo. Worth a human decision; if the
"evaluate on play" reading is chosen, the fix is a callable/`cost_mod` hook rather than a stored
integer. (The `to a minimum of 1 €$` half is right: `ops.play_cost` floors any reduction at 1 when
the base cost is ≥ 1 — verified at 1, 2 and 3 min Gigs.)

**N-NOTE — "Reveal" is not modelled as information for `sasha-yakovleva-wont-let-you-down`.**
"ATTACK: **Reveal** the top card of your deck and add it to your hand." The script (wnc.py:1427-1429)
moves the card to hand without marking it known to the Rival (`c.look_at` / `revealed=` exist for
exactly that). It is a set-wide convention rather than a defect of this card —
`judy-alvarez-nothing-to-doubt` reveals the same way, with a comment saying so — so fixing it is a
pool-wide decision and there is no zone/power/hand-size outcome to assert.

**N-NOTE — `johnny-silverhand-rocking-renegade` has no `legal` guard.**
The ability (wnc.py:1310) can be activated with no friendly Units on the field: you pay, Johnny is
spent, and `c.choose([])` does nothing. Legal by the printed text (the cost is paid to activate),
but sibling cards in the batch guard the same shape — Panam's ability carries
`legal=lambda c: bool(c.gear()) and any(...)` (wnc.py:1298). Style only, no rules consequence.
