# Batch B02 — cross-cutting pass: the modifier family

One mechanism, whole pool: every card that writes a mod (`EffectCtx.mod` / `GameState.add_mod`)
and every engine site that reads one. Authority order: `data/cards/wnc.json` `text` →
`docs/rules.md` → `docs/rulings.md`.

Cards named for this batch (14): chrome-fang, westbrook-netrunner, reboot-optics, safety-override,
mox-inciters, gunpoint-diplomacy, memory-relapse, maxtac-suppression-team, chrome-reverie,
cyberpsychosis, octant, sandevistan, towerfall, pyramid-song. All 14 read end to end, plus every
other writer and reader of the 14 mod names.

**Headline:** two writers in the pool print the prohibition *"it can't ready until your next turn"*
(Memory Relapse, Pacifica Netrunner) and both record it as `F_NO_READY_NEXT`, a flag that exactly
one site in `src/` reads — the start-of-turn Ready step. The other nine places that ready a card
(`EffectCtx.ready`, used by Sandevistan, Saul Bright, Panam, Modded Muramasa, Maxtac Squadron,
Wraith Marauders, Pepe Najarro, Johnny Silverhand *Never Stop Fighting*) never consult it, so the
banned Unit readies anyway — Johnny readies himself *on the very turn Memory Relapse named him*.

Two footnotes a per-section reader could not have produced:

* `attack_gigs_now` is **read** by `legal.attack_permission` and written by nothing in the pool.
  That is harmless (a read with no writer prints no card), and it is the mirror image of
  `must_attack`, which is written twice and read nowhere. Together they are the pool's only two
  halves of a mod that does not join up.
* The *only* mod whose subject is a player rather than an instance and whose read site is a
  **card** rather than the engine is none: every player-subject mod (`protect_*`, `cost_*`,
  `next_*`, `listener`) is read by the engine. There is no card in the set that reads another
  card's mod, so a mod with no engine reader is by construction a printed effect that does nothing.

## 2. `AUD-memory-relapse-2` — a prohibition recorded as a one-step skip

**Printed:** Memory Relapse — `"Spend a rival Unit. It can't ready until your next turn. …"`
Pacifica Netrunner prints the same clause (`"a rival Unit can't ready until your next turn"`).

**Majority pattern.** Every other "until your next turn" restriction in the set is stored as a mod
with `until_my_next_turn=True` and is therefore consulted *wherever the restricted action is
attempted*: Chrome Reverie's `cant_attack` is read by `legal.attack_permission`, which every
attack goes through; Chrome Fang's and Westbrook's `protect_*` are read by `steps.stealable`.
The two `can't ready` cards are the departure: `EffectCtx.cant_ready` does not write a mod at all,
it sets `F_NO_READY_NEXT` — the flag the engine also uses for the first-player handicap — and the
only site in `src/` that reads that flag is `steps.ReadyStep`, the start-of-turn untap. Nine
`ready()` calls in `wnc.py` and `ops.ready` itself never look at it.

**Consequence (the test).** Memory Relapse spends the rival's Johnny Silverhand *Never Stop
Fighting* and forbids it to ready. Still on that same turn, a friendly attacker feeds Johnny a
fight; Johnny wins, his own trigger ("The first time this Unit wins a fight each turn, ready it")
readies him, and a ready Unit can no longer be attacked (`docs/rules.md`: "Ready Units can't be
attacked"). The printed board state — Johnny spent, and therefore still a legal target for the
second attacker that would trash him — is not the board the engine produces.

Sandevistan (this batch) is the same violation one step later: "At the end of your turn, ready this
Unit or Legend" readies a Memory-Relapsed host at the end of the rival's turn, i.e. still before
the Memory Relapse player's next turn. Johnny is used for the test because his ready lands
*mid-turn*, on the very turn the prohibition was written, where no boundary reading can rescue it.

Controls: (a) the identical board with a rival Unit that has no ready trigger — it stays spent and
the second attacker does trash it, so the observable and the board are sound; (b) Memory Relapse
*is* honoured at the rival's Ready step, so the prohibition is recorded, just not enforced.

## 3. `AUD-safety-override-1` — "loses a fight" skips the tie

**Printed:** `"QUICK: The next time a friendly Unit loses a fight this turn, defeat the opposing
rival Unit."`

`steps.fight` computes `a_wins` / `t_wins`, and reads `next_loss_defeats_winner` only inside
`if a_wins:` and `if t_wins:`. A tie satisfies neither, so on a tie the mod neither fires nor is
consumed. But ruling 010 is explicit — *"Ties: both lose and both are defeated (CR 9.17.3)"* — and
the same ruling keeps a 0-power fight from defeating anybody (CR 9.19.2), which is precisely the
board where the difference shows: two 0-power Units tie, both lose, both survive, and Safety
Override should defeat the opposing rival Unit. It does nothing.

This is the shape `AUD-maelstrom-zealots-1` filed against Maelstrom Zealots' *"When this Unit loses
a fight"* trigger; the brief asks for the same shape elsewhere and this is elsewhere — a different
card, a different code site (the mod read in `steps.fight`, not an event handler), and a fix to
either one leaves the other unfixed. Control: the decisive loss, where Safety Override does trade.

## 4. Examined and not filed

**4.1 Read sites that are narrower than the action they gate.** `steal_fewer` (take-control,
"A rival Unit steals **1 fewer Gig** this turn") is read only in `ResolveAttackStep`, so an
effect-driven steal — Gorilla Arms, Appetite for Destruction — takes its full count. That is
exactly `AUD-chrome-fang-1` / `AUD-westbrook-netrunner-1` (a05) one mod over, and the fix is the
same fix: route effect steals through the shared path. Recorded here rather than filed a third
time. Likewise Evelyn Parker's `⊡: A rival Unit must attack next turn if it can` is dead for the
same reason `AUD-mox-inciters-1` is dead, and will come back to life with the same fix.

**4.2 Prevention vs. instruction ordering in `steps.fight`.** The three "no defeat" mods
(`no_defeat_in_fight`, the 0-power rule, `next_fight_no_defeat`) are applied first, and
`next_loss_defeats_winner` then sets `defeat_a` / `defeat_t` back to `True` unconditionally — so
Safety Override defeats a winner that Muamar Reyes protected with *"A friendly Unit can't be
defeated in a fight this turn."* The engine's own precedent elsewhere is that a printed "can't"
beats a printed "can" (MaxTac Suppression Team overrides ADRENALINE — confirmation 2 below), which
argues the prohibition should win. Against that, Safety Override's defeat is arguably an *effect*
defeating the Unit rather than the fight defeating it, and Muamar's clause says "in a fight". The
card text does not settle it, so it is recorded, not filed.

**4.3 `cost_go_solo` is consumed after one GO SOLO.** `ops.consume_cost_mods` clears the mod on the
first GO SOLO, and nothing limits GO SOLO to once per turn, so a second Legend that turn pays full
price. Nocturne prints "**A friendly Legend** may use GO SOLO for -2 €$ this turn" — the singular
subject makes one-Legend consumption a defensible reading, so this is not a finding. (Contrast
Alt Cunningham's "your **next** Program this turn", where consumption is certainly right.)

## 5. Clean

Read against their printed text and found correct, with the mod-family detail that mattered:

* **chrome-fang / westbrook-netrunner** — subject, direction of the comparison (`>` vs `<`),
  thief-type gate, and the `until_my_next_turn` lifetime across the rival's whole turn. The
  Legend-thief question (Chrome Fang says "Units" and does not gate on thief type) is *not* a
  deviation: ruling 015 makes a GO SOLO Legend on the field a Unit, and that is the only way a
  Legend ever steals. Confirmation 1 pins it.
* **maxtac-suppression-team** — `suppress_new_units` is keyed to the *opponent* of the lagged Unit,
  applies only while the Unit has Lag (ruling 039 makes Lag exactly "played this turn"), and beats
  ADRENALINE and the `attack_units_now` grants. Confirmation 2.
* **chrome-reverie** — the second sentence ("If you control a min Gig, you may Call a Legend for
  free") sits *outside* the `choose` continuation, so it still runs when the rival controls no Unit
  to name. This is the Pass-A shape #1 board, and this card passes it. Confirmation 3.
* **cyberpsychosis** — `+3 per equipped Gear` reads the host's Gear at resolution; the target is
  "an equipped Unit" unqualified, and the script correctly offers both players'; the listener and
  `defeat_at_end` both expire with the turn. (Its tie gap is already `AUD-cyberpsychosis-1`.)
* **octant** — `max(1, base - gigs_8plus(c))`, friendly Gigs only, floor of 1, and `play_cost`
  re-applies the same floor to any further reduction.
* **towerfall / pyramid-song** — the `-N power` clause runs before the `power 0` clause when both
  are chosen, and the bottom-deck candidate list is computed at that moment; ruling 029's floor at
  0 is what makes the second clause reachable at all.
* **sandevistan** — readies its host at the end of its controller's turn only, and only while
  equipped. (It is a *violator* of §2, not a card with a bug of its own.)
* **gunpoint-diplomacy** — side and target scope checked: `c.units()` is friendly, and the
  less-Street-Cred branch hands the choice to the rival while the other branch grants both effects,
  matching "Give a friendly Unit these effects". Only the one-shot duration is wrong, already filed.
* **mox-inciters / memory-relapse / reboot-optics** — remaining clauses correct; their open
  findings are the ones listed above.
