Run a tournament

Every pair plays mirrored games until the cap or until the SPRT is sure. Reports rank decks by Bradley–Terry rating, field win rate and Nash weight.

Run a league

AI builders with different philosophies invent decks, improve them against each other, then play a round robin. Each generation replaces the worst deck, feeds the knowledge store (learned card values) and the hall of fame.

Generate decks

Build many different decks at once. Each comes from a personality that picks the Legends it likes best, with a novelty penalty so the batch spreads across the Legend space and a similarity floor so no two are near-copies. Optionally screen them against a panel and keep only the best.
